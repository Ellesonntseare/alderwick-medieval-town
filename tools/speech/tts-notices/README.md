Dataset: CSTR VCTK Corpus, University of Edinburgh, CC BY 4.0: https://datashare.ed.ac.uk/handle/10283/3443 . Upstream model card is included under models/tts. Preserve these notices when redistributing the runtime. Review model/dataset terms for your use.

All generation is local; there is no cloud API or voice cloning.
