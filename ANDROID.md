# Alderwick for Android

The Android build is a separate landscape project generated by `python tools/prepare_android.py`. It leaves the desktop game unchanged. The private repository's **Build Android** workflow creates a signed debug ARM64 APK for direct installation; this is not a Play Store release.

Touch controls: left pad moves, drag the right side to look, Run toggles running, Jump jumps, Use interacts with nearby doors/furniture/items, Talk starts or closes a nearby conversation, View changes perspective, and Menu expands the town controls. Hold Use for workbench tasks. Android starts with Performance graphics and 512-pixel texture import limits. A real phone performance check is still required.

Jobs, family routines, market transactions, missions and movement are local game systems. Free-form generated conversation, transcription and neural voices use the existing PC services over the same private Wi-Fi:

1. On the PC, open **Start Phone AI.cmd** and keep its window open. This starts the existing local AI/voice services and a paired LAN bridge on port 34322.
2. In the Android game, select **Connect to PC AI** and paste the connection address displayed by that window. The pairing code is stored only on the PC and phone, excluded from Git.
3. If Windows requests network access, permit it for your private network. Do not expose port 34322 to the internet. Without the PC connection, the town remains playable but generated dialogue and neural speech are unavailable.

The bridge accepts only its fixed AI/voice endpoints and requires the pairing code. It proxies to loopback services; it is not a general URL or file proxy. Windows Python, downloaded neural models, private histories, recordings, keystores and personal saves are not included in the APK or Git repository.

The Android project retains the same third-party asset attributions and restrictions. In particular, noncommercial assets do not become commercially licensed because they are packaged for Android. See the asset credit files before any distribution.
